# My Wealth Live

Price action scanner for synthetic indices and major forex pairs, using a live price feed.

- Live candles from Deriv's public WebSocket feed (no account or key needed)
- Chart with timeframes (1m to 4h), zoom, pan and crosshair
- Entry, stop loss and take-profit levels for locked trade signals
- 1, 2 and 5 minute binary signals with a live record, history and filters
- Risk settings, backtest and CSV copy

It opens on EUR/USD. Forex is closed on weekends, so those pairs show "closed" until the market reopens. Synthetic indices run all week.

This app reads prices only. It does not place trades. It is not financial advice.

## Publish with GitHub Pages
1. Create a public repository and upload `index.html` and this README.
2. Settings > Pages > Deploy from a branch > `main` / `(root)` > Save.
3. After about a minute it is live at `https://YOUR-USERNAME.github.io/REPO-NAME/`.

## Edit
Open `index.html` on github.com, tap the pencil icon, change it, and Commit changes. Or press `.` on the repository page for the web editor.
