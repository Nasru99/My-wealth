# SpeakEasy English Tutor

A single-file web app: speaking conversation mode, lessons with quizzes, and progress tracking.

## Use it
1. Open the site (GitHub Pages link).
2. Go to the **Progress** tab, paste your Claude API key, and tap **Save key**.
   The key is stored only in your browser. Never put it in the code.
3. Use **Talk** for voice conversation and **Learn** for lessons.

## Publish with GitHub Pages
1. Create a repository and upload `index.html` (and this README).
2. Settings > Pages > Build and deployment > Deploy from a branch > `main` / `(root)` > Save.
3. After about a minute, the site is live at `https://YOUR-USERNAME.github.io/REPO-NAME/`.

## Edit it
- On github.com, open `index.html`, tap the pencil icon, change it, then Commit changes. The site updates in about a minute.
- Or press `.` on the repository page to open the web editor.
